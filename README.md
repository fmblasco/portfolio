# Portfolio - Francisco Blasco

Personal portfolio built with Quarto to present my research, data science skills, and applied political-economic analysis.

## Live Demo

Access the published version at:

[https://fmblasco.github.io/portfolio/](https://fmblasco.github.io/portfolio/)

## Overview

This portfolio was built as a static site generated via Quarto. The goal is to combine a strong, clean visual identity with scientific publishing standards to present complex data analysis, econometric modeling, and institutional network mapping.

Site sections:

* Home (About Me)
* Projects & Applied Research
* Individual Case Studies

## Features

* Scientific and academic publishing format optimized by Quarto
* Responsive layout for desktop and mobile (Cosmo theme)
* Seamless integration with data science workflows
* Detailed documentation of methodologies (SNA, NLP, Econometrics)

## Stack

* **Framework:** Quarto
* **Languages:** Markdown, HTML, CSS
* **Deployment:** Git & GitHub Pages
